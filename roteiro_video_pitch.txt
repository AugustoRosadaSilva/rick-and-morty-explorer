ROTEIRO SUGERIDO — VÍDEO PITCH (ATÉ 4 MINUTOS)

0:00–0:30 | Apresentação
"Olá! Este é o Rick & Morty Explorer, um site desenvolvido com HTML, CSS e JavaScript. O objetivo é apresentar personagens do desenho utilizando dados de uma API pública."

0:30–1:20 | Demonstração visual
"Na página inicial temos uma apresentação temática. Na área de personagens, os cards mostram nome, imagem, status, espécie, gênero, origem e localização. Também é possível pesquisar por nome, filtrar por status, favoritar personagens e navegar entre páginas."

1:20–2:10 | Demonstração da API
"Agora vou mostrar a integração. No JavaScript, a função loadCharacters utiliza fetch() para consultar o endpoint https://rickandmortyapi.com/api/character. A resposta é verificada com response.ok e convertida para JSON. Os dados dos personagens ficam disponíveis em data.results."

2:10–3:10 | Criação dinâmica dos cards
"A função createCharacterCard recebe um personagem e cria os elementos HTML com document.createElement(). Depois, os elementos são organizados com append e appendChild. No final, renderCharacters percorre a lista e insere cada card na grade. Isso comprova que os cards não estão fixos no HTML: eles são criados a partir dos dados da API."

3:10–3:40 | HTML e CSS
"O HTML contém as áreas principais e os espaços onde o JavaScript insere os dados. O CSS define cores, tipografia, cards e responsividade para diferentes tamanhos de tela."

3:40–4:00 | Encerramento
"Este projeto demonstra o consumo de uma API com Fetch, manipulação do DOM e criação dinâmica de elementos. Obrigado!"

DICA PARA A GRAVAÇÃO
- Mostre o site funcionando.
- Abra o DevTools do navegador com F12.
- Na aba Network, selecione Fetch/XHR e atualize a página para mostrar a chamada da API.
- Na aba Sources ou no VS Code, mostre `fetch`, `document.createElement` e `appendChild`.
- Faça uma busca, aplique um filtro e navegue para a próxima página.
